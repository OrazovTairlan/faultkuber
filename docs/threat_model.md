# Threat model (synthetic AITU platform, endterm)

Assets: student accounts and sessions, registration records, availability of the service, backups, configuration and secrets.
Actors: legitimate student, malicious student (misuse of own access), anonymous external attacker, compromised pod, operator error.
Trust boundaries: internet -> gateway; gateway -> services; services -> database; cluster nodes -> backup vault.

| ID | Threat | STRIDE | Control | Implemented in | Evidence |
|---|---|---|---|---|---|
| T1 | Password guessing / credential stuffing | Spoofing | PBKDF2 password check (no user enumeration), lockout after 5 failures per account (30 s), per-source failure cap, login routed to a fixed Auth replica, audit events LOGIN_FAILED / ACCOUNT_LOCKED, alert BruteForceLogin | service.py: AuthHandler.login, LoginGuard, auth_replica_for | E5 (A7, A8), E6 (lockout at attempt 6); unit LoginGuardTests; integration lockout test |
| T2 | Token forgery, tampering, reuse of expired tokens | Spoofing / Tampering | HMAC-SHA256 signed tokens with exp (15 min) and role; constant-time comparison; signing key only from a Kubernetes Secret | service.py: make_token, parse_token | E5 (A2, A5); unit TokenTests (tamper, expiry, garbage) |
| T3 | Broken authorization: reading or writing another student's data, admin access by a student | Elevation of privilege / Information disclosure | Ownership check at the gateway and again in Registration (defence in depth), administrator role for /admin/count, audit FORBIDDEN_ACCESS, alerts ForbiddenAccessSpike / UnauthorizedAccessSpike | service.py: GatewayHandler.authenticate, RegistrationHandler | E5 (A3, A4, A6): baseline violated, endterm denied; integration AuthorizationTests |
| T4 | Malformed or hostile input: injection strings, wrong types, oversized bodies, path attacks | Tampering / Denial of service | Strict validation (anchored regex, JSON types, course whitelist), body limit 1 KB (413), path limit, record schema check in the DB, 4xx instead of 5xx, alert MalformedRequestBurst | service.py: read_json, STUDENT_RE, valid_record | E6 (12 malformed cases, junk records = 0); integration InputValidationTests; unit ValidationTests |
| T5 | Request flooding by one client | Denial of service | Token bucket per account (20 req/s, burst 40) and per source (400 req/s), 429 + Retry-After, timeouts and circuit breakers, alert RateLimiting | service.py: TokenBucket, GatewayHandler | E6 (960-request burst), E3; unit TokenBucketTests; integration RateLimitTests |
| T6 | Duplicate or replayed requests | Tampering | Deterministic record id (student:course), created flag, 200 duplicate answer, audit DUPLICATE_REGISTRATION | service.py: RegistrationHandler.create, Store.put | E7 (replay of 300 requests creates 0 records); integration duplicate test |
| T7 | Data destruction or encryption (ransomware), deletion of backups | Tampering / Denial of service | Fail-closed data tier, synchronous replica, immutable off-namespace backups and timed recovery drill (Assignment 4) | service.py: Store; k8s/security/20-vault.yaml; security/vault/ | Assignment 4 drill (RTO 8.0 min); E7 (node kill during writes) |
| T8 | Lateral movement from a compromised pod | Elevation of privilege | Default-deny NetworkPolicy with explicit allows, Pod Security (non-root, dropped capabilities, seccomp), egress to the internet denied | k8s/security/10-networkpolicies.yaml, k8s/*.yaml | Segmentation matrix re-run on the endterm stack (results/endterm/segmentation.json) |
| T9 | Information disclosure through logs and errors | Information disclosure | Logs carry ids and decisions only, never passwords, tokens or the signing key; generic error text for authentication failures | service.py: audit, access log | Log scan of all endterm pods (results/endterm/log_secret_scan.json) |
| T10 | Dependency failure or outage (instance, database, non-critical service) | Denial of service | 2 replicas, probes, timeouts (200 ms) with one bounded retry, circuit breakers, 503 + Retry-After, stale-cache graceful degradation for courses and timetable, alerts ReplicaUnavailable / DatabaseUnavailable / DegradedMode / HighErrorRate | service.py: forward, db_request, STALE_CACHE | E1, E2, E4, E7 |
| T11 | Unsafe configuration (default secret, bad timeouts) | Spoofing | Configuration check at start and in /readyz; refuses to start in production with a default or short secret; Pod Security enforced on the namespace | service.py: validate_config; k8s/security/00-namespaces.yaml | Unit ValidationTests; found a real defect during the first deployment (see lessons learned) |
| T12 | Vulnerable third-party dependencies | Tampering | Services use the Python standard library only; image runs as non-root with a read-only root filesystem | app/Dockerfile | Not tested (design measure); base image digest is not pinned - listed as a limitation |
